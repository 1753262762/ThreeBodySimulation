# 前端工程交付计划

## 目标与技术基线

将“参数实验室”原型升级为正式应用，使用 Vue 3、TypeScript、Vite、Vue Router、Pinia、Canvas 2D 和 ECharts。前端不实现物理计算，只编辑配置、消费服务端快照、绘制状态并生成报告页面。删除其他四套原型及总览的生产路由，根路由直接进入参数实验室。

前端接口类型必须从 `contracts/openapi.yaml` 与 `contracts/ws-events.schema.json` 生成到 `src/generated/`，生成文件禁止手工修改。后端未完成时使用 MSW 和契约示例并行开发。

## 功能模块

```text
features/experiments     参数草稿、N 体编辑、队列和导入导出
features/simulation      Canvas、投影、轨迹和视图操作
features/telemetry       KPI、能量、角动量和距离图表
features/reports         报告页面、打印样式和下载入口
stores                   API、WebSocket、草稿、队列和连接状态
generated                OpenAPI/JSON Schema 生成类型
```

正式路由：

```text
/                       参数实验室
/experiments/:id        指定实验
/reports/:id            可打印实验报告
```

## 参数实验室交互

- 左侧面板使用“实验参数 / 任务队列”两个标签页。
- 参数草稿支持 2–20 个天体的新增、复制、删除、排序和编辑。
- 每个天体可编辑名称、颜色、质量、三维位置和三维速度。
- 全局可编辑时间步长、引力常数、软化长度、最大步数或目标模拟时间。
- 修改只进入草稿；点击“应用并重新计算”后先调用校验接口，再以 `RESTART` 提交。
- 提供 A–D 内置预设、JSON 导入和配置 JSON 导出。
- 队列展示状态、进度、结束条件、预计剩余量和占用空间；支持暂停、继续、单步、取消和拖动排序。
- SI/天文单位可切换；Pinia 内部和 API 始终保存 SI，显示层转换为太阳质量、AU、km/s。

## Canvas 与实时数据

- 支持 XY、XZ、YZ 三个正交投影，不引入 Three.js。
- 支持缩放、平移、适应窗口、轨迹开关、标签开关和参考网格。
- 使用设备像素比处理高清屏；绘制循环与 WebSocket 接收解耦，通过 `requestAnimationFrame` 插值最新两个快照。
- 每个天体最多绘制最近 2,000 个轨迹点，切换投影时复用三维轨迹数据。
- WebSocket 根据 `sequence` 丢弃重复或过期消息；断线使用带上限的指数退避重连。
- 重连时暂停增量应用，REST 全量同步完成后再恢复。
- `NEAR_ENCOUNTER` 显示非阻塞警告、场景标记，并写入报告事件列表。

## 图表、报告与导出

- KPI：总能量、相对能量漂移、角动量、最近距离、模拟时间和计算速率。
- ECharts 展示能量趋势、角动量趋势和天体间距离；图表使用服务端采样数据。
- `/reports/:id` 展示实验配置、结束原因、指标摘要、事件、轨迹说明和图表。
- 提供专用打印 CSS；“导出 PDF”调用浏览器打印功能，不在前端生成二进制 PDF。
- 报告页提供配置 JSON、轨迹 CSV 和报告数据 JSON 下载。
- 明确标注 CSV 为分层采样数据，并显示实际采样步长。

## 并行开发与 Mock

1. 契约基线合并后生成 TypeScript 类型并提交生成结果。
2. 根据 `contracts/examples/` 建立 MSW：预设、列表、详情、动作、报告及 WebSocket 事件回放。
3. 先完成表单、队列和状态机，再完成 Canvas 与图表。
4. 使用环境变量 `VITE_API_MODE=mock|live` 切换 Mock 和真实服务。
5. 联调只允许修改 API 适配器；组件不得依赖后端 DTO 的未转换字段。

## 实施顺序

1. 清理未选中的方案路由与样式，保留参数实验室视觉系统。
2. 建立生成类型、Pinia Store、API Client、错误处理和 MSW。
3. 完成参数草稿、单位转换、N 体编辑与后端校验映射。
4. 完成实验队列及命令交互。
5. 将静态 SVG 场景替换为 Canvas 2D，并接入快照和轨迹增量。
6. 接入实时指标、ECharts、近距离事件与重连机制。
7. 完成报告、打印样式和 JSON/CSV 下载。
8. 将 `dist/` 接入 Maven 打包，验证单 JAR 离线运行。

## 测试与验收

- 单元测试：SI/天文单位双向转换、表单校验、草稿差异和队列状态映射。
- 组件测试：2/20 天体编辑、非法输入、操作按钮权限及导入错误。
- 渲染测试：三个投影、缩放、平移、高清屏、轨迹上限及窗口调整。
- 通信测试：乱序消息、重复消息、断线重连、全量恢复及服务端错误。
- Playwright：创建、排队、运行、暂停、重启、完成、报告和下载全流程。
- 视觉检查：1024×768、1440×900、1920×1080。
- 验收命令为 `npm run build`、单元测试和 E2E；浏览器控制台不得出现未处理异常或外部 CDN 请求。
